## 🌟 Project Overview
This repository contains my personal portfolio website, designed to demonstrate mastery of **HTML5**, **CSS3**, and **JavaScript**. The website serves as a professional hub to showcase my projects in **Artificial Intelligence**, **Data Science**, and **GRC Systems**.

The design features a **"Galactic Space Theme"** reflecting the futuristic nature of AI technologies.

---

## 📋 Project Requirements & Features Implemented
This project fulfills all the criteria specified in the ISY 208 assignment:

### 1. Structure & Semantic HTML
- [x] **Multi-page Website:** Includes Home, About, Projects, and Contact pages.
- [x] **Navigation Bar:** Consistent navigation linking all pages.
- [x] **Semantic Tags:** Utilized `<header>`, `<nav>`, `<main>`, and `<footer>` for better accessibility and SEO.

### 2. Styling (CSS)
- [x] **External CSS:** All styles are managed in `css/style.css`.
- [x] **Custom Design:** A unique space-themed color palette (Dark Navy & Cyan) with no reliance on external frameworks like Bootstrap.
- [x] **Responsive Layout:** Uses CSS Grid for the projects section to adapt to different screen sizes.

### 3. Interactivity (JavaScript)
- [x] **Form Validation:** The Contact page uses JavaScript to ensure no empty fields are submitted.
- [x] **User Feedback:** Custom `alert()` messages provide immediate feedback upon form submission.

## 🚀 How to Run Locally

Since this is a static website, no complex installation is required.

### Option 1: Direct Open

Simply double-click the `index.html` file to open it in your default web browser.

### Option 2: Python Server (Recommended)

If you have Python installed, you can run a local server to simulate a production environment:

```bash
python -m http.server
```

Then open `http://localhost:8000` in your browser.
